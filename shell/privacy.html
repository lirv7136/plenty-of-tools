Privacy

Last updated 16 September 2026.

{{brand}} is a set of tools that run entirely in your web browser. The short version: nothing you type, open or load into a tool is sent to us, because there is no server for it to go to.

What the tools do with your data

  • Files and text you provide (a CV, a bank statement, a PDF, an image) are processed on your own device and never uploaded. Closing the tab clears them, unless a tool offers to save a draft in your browser's local storage, which stays on your device and which you can clear at any time.
  • Optional street maps in the GPX Route Builder load tiles from OpenStreetMap only when you turn them on. Tile requests share the map area you view and your IP address with OpenStreetMap; your GPX files are not uploaded. The coordinate grid and file tools work without street tiles. See the OpenStreetMap Foundation privacy policy.
  • Transcription model downloads come from Hugging Face when you start Browser Transcription. Hugging Face and its file-delivery providers receive your IP address and model requests; audio and transcripts are processed locally and never uploaded. If enabled, only model files are saved in this browser’s cache. Use “Remove cached model” in the tool to delete them. See Hugging Face’s privacy policy.
  • Google sign in (Google Storage Analyser only) asks for read only access to your Drive file metadata: names, sizes, types and dates. It cannot read the contents of files and cannot change or delete anything. The access token is held in the memory of that tab, is never stored, and is revoked when you press "Sign out". No Google data is transmitted to us. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

What the site itself collects

  • Hosting is on Cloudflare Pages, which sees the same request data any web host sees (IP address, browser, page requested) in order to serve the page.
  • Analytics, when enabled, is Cloudflare Web Analytics: page views only, no cookies, no fingerprinting, no cross site tracking.
  • There are no advertising trackers, no third party scripts other than Google's sign in library on the one tool that uses it, and no accounts.
