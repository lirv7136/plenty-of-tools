Google Storage Analyser

See what is actually using your storage before you pay for more. Read only, runs in this tab, and the access token never leaves your browser. Is it worth paying for Google One?

Asks only for read access to file names, sizes and types (drive.metadata.readonly). It cannot read what is inside your files and cannot delete anything. You delete in Google Drive itself, using the links in each row.

What this can and cannot see

  • Drive files: every file you own, with size, type, last modified date and whether it is in the trash. Duplicates are found by content checksum, so two copies of the same video are caught even when the names differ.
  • Gmail and Photos: Google only exposes these as one combined number through the Drive API, so they are shown together. Use the Photos storage manager link to see which photos are large or blurry, and the Gmail search link for heavy attachments.
  • Files shared with you do not count against your storage and are left out of the totals.
  • Nothing is deleted from here. Every row links to the file in Drive so you can decide.
