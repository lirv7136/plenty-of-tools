Authors: Xuebin Qin, Zichen Zhang, Chenyang Huang, Masood Dehghan,
        Osmar R. Zaiane, Martin Jagersand.
Project: https://github.com/xuebinqin/U-2-Net
Apache License 2.0: U2NET-LICENSE.txt (in this directory).
Paper: https://arxiv.org/abs/2005.09007
The small pretrained model is distributed as u2netp.onnx from the rembg
project's v0.0.0 model release, unchanged:
https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2netp.onnx
Upstream rembg validation MD5: 8e83ca70e441ab06c318d82300c84806.
The browser implementation uses 320 x 320 RGB input, image-max scaling,
ImageNet normalisation and min/max mask scaling. It uses browser image
resampling and retains input alpha when applying the mask.
