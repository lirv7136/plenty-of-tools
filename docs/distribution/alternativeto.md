# AlternativeTo submissions

Submit at alternativeto.net/manage/new-app/ from the personal account, one per tool. Common
fields for every entry: licence **Open Source, MIT**; platforms **Online**, **Self-Hosted**;
tags **privacy-focused**, **no-registration**, **works-offline** where true; source URL
https://github.com/lirv7136/plenty-of-tools. Each description is one paragraph, factual, no
adjectives about quality. The "alternative to" list is what makes the listing findable, so
be generous but accurate.
