# AlternativeTo submissions

Account: **lirv7136** (created 26 September 2026). AlternativeTo reviews new apps before they
publish and wants the account to be about 7 days old first, so **submit from 3 October**, after
the email address is verified. Submit at alternativeto.net/manage/new-app/, one entry per tool.

Common fields for every entry: licence **Open Source, MIT**; platforms **Online**,
**Self-Hosted**; tags **privacy-focused**, **no-registration**, and **works-offline** only where
the table says so; source URL https://github.com/lirv7136/plenty-of-tools. Each description is
one factual paragraph with no adjectives about quality. The "alternative to" list is what makes
a listing findable, so be generous but accurate.

**Order.** Start with the umbrella entry, then the four tools the engagement plan pushes for
search (Invoice Generator, Ringtone Maker, Settle Up, Sign a PDF), then the rest a few a day. A
burst of 20 submissions from a new account on one day is more likely to be held for review.

## Umbrella entry (submit first)

**Plenty of Tools**, https://plentyoftools.io, alternative to TinyWow, 123apps, Smallpdf,
iLovePDF, 10015.io.

> A collection of 19 free single purpose tools that run entirely in the browser: nothing is
> uploaded, no accounts, no ads. Each tool replaces a product that charges at the moment you
> need the result, and each has a comparison page explaining when the paid product is still the
> right choice. Installable as an app, and eleven tools keep working with no connection once
> opened.
