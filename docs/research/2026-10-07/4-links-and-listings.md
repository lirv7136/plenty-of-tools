# 4. Links and listings: every realistic place, with exact routes

Research pass, 7 October 2026. Angle: places where Plenty of Tools can get a link or a listing,
checked live, with the submission route and rules, so an agent prepares everything and Lachlan
only pastes and clicks submit. It extends section 5 of `docs/PLAN-DISTRIBUTION-2026-Q4.md` and
`docs/distribution/alternativeto.md`.

Every venue below was fetched on 7 October 2026 unless the row says "not verified". GitHub lists
were checked through the GitHub API (stars, last push, recent merged pull requests, contribution
file). Value figures are estimates, not measurements.

**How to read the value column.** **H** = likely 50+ real visits a month or a strong, relevant
link; **M** = roughly 10 to 50 visits a month or one decent link; **L** = under 10 a month, or a
link that mostly helps crawling. Nearly every directory and GitHub link is `nofollow`; the point
is referral visits and getting Google to crawl the 29 pages it has found but not fetched.

## 4. Rules to carry into every submission

1. **Disclose** "I built it" in every PR body and email. Say how it was built (AI coding agents,
   checked by hand and tests) on Peerlist, Product Hunt, Indie Hackers, Lissy93 and anywhere a
   form asks.
2. **Never ask for votes**, including on Uneed, where staying listed depends on them.
3. **One tool per PR**, separate days, so a flooded maintainer sees considered submissions, not a
   burst.
4. **No reciprocal badges or backlinks.** Fazier, Twelve Tools, Startup Fame, Open Launch,
   TinyLaunch's dofollow and SaaSHub's dofollow all want one; we take the plain listing or skip.
5. **No paid listings.** None was judged worth it at zero traffic.
